# Конвертер тестов Word → TXT

## EXE для заказчика на Windows

Для сборки на Windows установите Python 3 с python.org (с поддержкой Tcl/Tk), затем дважды нажмите `build_exe (1).bat`. Скрипт создаст окружение `.venv_windows`, установит зависимости и соберёт `dist/WordToTxt.exe`.

Заказчику передавайте только `WordToTxt.exe`. Устанавливать Python на его компьютере не требуется. При двойном щелчке откроется окно выбора документов Word; результаты сохраняются рядом с ними.

Сборка с Mac через GitHub Actions:

1. Загрузите исходники, файлы зависимостей и `.github/workflows/build-windows.yml` в свой репозиторий GitHub.
2. Откройте **Actions → Build Windows EXE → Run workflow**.
3. После успешной сборки скачайте артефакт **WordToTxt-Windows-x64** и извлеките из ZIP файл `WordToTxt.exe`.
4. Проверьте на Windows выбор Word-документа, создание TXT и отчёт, затем передайте EXE заказчику.

PyInstaller собирает приложение для системы, на которой запущен. `build_mac.command` создаёт приложение macOS и не подходит для Windows EXE.

## Запуск на macOS

1. Дважды нажмите **Запустить.command** в Finder.
2. При первом запуске программа создаст локальное окружение Python и установит библиотеку для чтения Word. Для этого нужен интернет.
3. В открывшемся окне выберите один или несколько файлов `.docx`.
4. Результаты `.txt` появятся рядом с исходными документами. После обработки программа покажет отчёт и предупреждения.

Если Python 3 отсутствует, установите его с https://www.python.org/downloads/macos/.

Из Терминала можно запускать так:

```bash
cd /Users/athena/Downloads/pytest
./Запустить.command
```

Можно передать документы напрямую:

```bash
./Запустить.command "/путь/к/тесту.docx"
```

Для ручного запуска на любой системе:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python test.py
```

На Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

## Формат исходного документа

Первый непустой абзац — тема. Вопросы начинаются с `1.` или `ВОПРОС №1`. Варианты ответа — с `1)`, `A)` или `А)` в последовательном порядке. Правильный ответ определяется по выделению текста: жирный, курсив, подчёркивание, цвет или маркер. Программа читает обычные абзацы; вопросы в таблицах не обрабатываются.

Файл `.txt` с тем же именем перезаписывается при повторной обработке.
